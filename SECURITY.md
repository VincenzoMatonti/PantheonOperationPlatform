# Security Policy

## Supported Versions

Security fixes are currently provided for the latest released version of Pantheon.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Pantheon, please do not open a public GitHub issue.

Report the vulnerability privately through the security reporting mechanisms provided by GitHub for this repository.

When reporting a vulnerability, please provide:

* A clear description of the vulnerability.
* The affected component or area.
* Steps to reproduce the issue.
* The potential security impact.
* Any relevant logs, screenshots, or proof of concept.
* A suggested mitigation, if available.

Please avoid publicly disclosing the vulnerability before it has been investigated and addressed.

## Security Scope

Security reports may concern, among other things:

* Authentication and authorization.
* API security.
* Secrets and credentials.
* Dependency vulnerabilities.
* Container and infrastructure security.
* Docker and local runtime configuration.
* GitHub Actions and CI/CD workflows.
* Data exposure.
* Injection vulnerabilities.
* Unsafe processing of external input.

## Responsible Disclosure

Pantheon follows a responsible disclosure approach.

Security vulnerabilities should be reported privately so that they can be investigated and, when necessary, fixed before public disclosure.
